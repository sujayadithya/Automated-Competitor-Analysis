# Scoring Rubric

## Info Density (1-5)
1 = Overwhelming — too many options/fields visible at once
3 = Mixed — some clutter, but main action is findable
5 = Only what's needed is shown, rest is progressive/hidden until relevant

## Steps-to-Value (1-5)
1 = 6+ clicks/steps to complete the action
3 = 3-5 steps, some unnecessary friction
5 = 1-2 clicks, minimal friction to complete the action

## Error Clarity (1-5)
1 = Generic error ("Something went wrong"), no next step
3 = Error names the problem but not how to fix it
5 = Specific, tells you exactly what failed and how to fix it

## Edge-Case Handling (1-5)
1 = No handling for partial failures, empty states, or limits — breaks silently
3 = Some edge cases handled, others fall back to generic states
5 = Every edge case (partial failure, empty state, limit reached) has a clear, designed state
